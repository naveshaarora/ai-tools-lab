# AI Tools Lab

A Python project containing core sorting algorithms and helpful utility functions, built utilizing version control workflows.

## Features
- **Sorting Methods**: Includes an implementation of the standard Bubble Sort algorithm.
- **Utility Module**: General-purpose functions for palindrome verification, word counting, and temperature conversion.

## Installation
Clone the repository to your local machine:
```bash
git clone https://github.com
```

## Setup & Implementation
- Developed using modular function components.
- Version control managed dynamically via distinct feature branching strategies.
